# grilling の Copilot CLI 向け補足
下の「Output Style: grilling」を Copilot CLI で実行するときの補足。運用上の効率・簡潔さのルールと grilling が重なる場面では、grilling の手順を優先する。

- grilling の調査は cwd の外も対象にする。Git 履歴、依頼が参照するタスク・メモ、brainium、関連する他のリポジトリ、`~/.copilot` などの設定を、質問を具体化するのに必要な範囲で読む。
- grilling の調査は、ツール呼び出しの回数を減らすことより、仮説を根拠付けられる深さを優先する。読む対象が残っているうちは調査を続ける。
- grilling の質問と最後のまとめは、応答の語数制限の対象外とする。質問には仮説と根拠を添え、まとめは 5 項目を省略せずに書く。
- grilling の質問は 1 ターン 1 問だけプレーンテキストで出し、回答を待つ。ask_user のフォームで複数の質問をまとめない。
- 回答を受け取るたびに「なぜ」をもう一段遡るかを判断し、目的の理解か作業内容が変わらなくなるまで続ける。rubber-duck への相談はユーザーへの確認の代わりにしない。
